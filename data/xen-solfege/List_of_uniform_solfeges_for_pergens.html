#1 (P8, P5) whole

There are no ups and downs. The basic solfege has 13 notes. The extended solfege uses -u/-o to augment/diminish an -a interval. The solfege can be further extended with -i/-e meaning doubly augmented/diminished.

  • G = P5, which = 700¢ + c for this and all other pergens
  • EU = vA1 = 0¢ (extended solfege only)
  • ^ = 100 + 7c (extended solfege only)

  • 5 = 2L3s (1\2 < P5 < 3\5) (for 3L2s, use P11/4 or P12/4, to avoid P5 > 3\5= 720¢)
  • 7 = 5L2s (4\7 < P5 < 3\5) (for 2L5s, perhaps use P11/3 or ccP4/5, to avoid P5 < 4\7 = 686¢)
  • 12 = 7L5s or 5L7s (4\7 < P5 < 3\5) (extended solfege only)
  • 19 = 12L7s and 7L12s (extended solfege only)

Meantone keyboards were usually tuned to the 4th mode (a fifthchain from Eb to G#).

The sequence of scales starts off with 6 sharps and ends with 7 flats and 3 double-flats:

  • C C# D D# E E# F# G G# A A# B C
  • C C# D D# E F F# G G# A A# B C
  • C C# D D# E F F# G G# A Bb B C
  • (and so on until it ends with)
  • C Db Ebb Eb Fb F Gb Abb Ab Bbb Bb Cb C

12edo's uniform solfege is a merging of the 2nd through 7th modes.

#2 (P8/2, P5) halves

There are two solfeges. Use solfege #1 if P5 > 700¢, and use solfege #2 if P5 < 700¢.

  • P = vA4/^d5 (solfege #1) or ^A4/vd5 (solfege #2) = 600¢
  • G = P5 = 700¢ + c, mingen = vA1/^m2 (solfege #1) or ^A1/vm2 (solfege #2) = 100¢ + c
  • EU = ^^d2 (solfege #1) = 0¢ or vvd2 (solfege #2) = 0¢
  • ^ = 6 ⋅ |c|

MOS scales covered:

  • 8 = 2L6s (either solfege) or 6L2s (solfege #1 only, P5 > 5\8 = 750¢)
  • 10 = 2L8s (either solfege) or 8L2s (solfege #1 only, P5 > 3\5 = 720¢)
  • 12 = 10L2s (solfege #1 only) or 2L10s (solfege #2 only)

Multi-edo pergens of the form (P8/m, ^1)

These pergens consist of multiple rings (copies of an edo) equally offset from one another. For example, Blackwood[15] tuned such that 5/4 is just has three 5-note rings. The offset is the difference between 5/4 and the nearest 5edo note (2\5), which is about 94¢. Thus the cents run 0, 94, 146, 240, 334, 386, etc. (146 = 1\5 - 94¢). Multi-edo pergens are named after the edo. For example, Blackwood is named "rank-2 5edo", meaning a rank-2 temperament that contains 5-edo.

Most pergens map the 5th to some nonzero number of generators, i.e., the 5th's genspan is nonzero. But multi-edo pergens map the 5th to zero generators and some number of periods. Thus in the mapping matrix, the 2nd number of the 2nd row is zero. In other words, the 5th is mapped to some note in the edo, and Sa is on the perchain not the genchain. (Incidentally, if Sa is on a genchain, but a different genchain than Da, the multigen is imperfect, e.g. (P8/2, M2/4).) Because both Da and Sa are on the perchain, the entire perchain uses the -a vowel. The genchains run De - Do - Da - Du - Di, Se - So - Sa - Su - Si, etc.

Multi-edo pergens only make sense musically if the edo's approximation of the 5th has a relative error < 25%. Otherwise there will be a more accurate Sa on another ring. For example, 4-edo with 34% error has 3/2 = 600¢, but an additional ring will add an interval between 600¢ and 750¢ that will be a better approximation. With 3-edo, error 24.5%, for 2\3 to be the best approximation, the generator must be more than twice the absolute error of 102¢, but less than half an edostep, leaving only the small range of 196-200¢. With 2-edo, only one ring can be added, because the 3rd ring will create a better 3/2.

If one were to add a better 3/2, and were to call that note Sa, the pergen would change from (P8/m, ^1) to (P8/m, P5).

In order for 10-edo's mapping to be valid, it must have an odd number somewhere in the top row and a nonzero number somewhere in the bottom row. They can't be in the same column. So rank-2 10-edo needs at least two more primes besides 2 and 3. This holds true for any multi-ring edo, like 14 or 15.
